# Go-to routing map

The agent consults this BEFORE asking where information lives. Keep it current -
every line here is a question the agent never has to ask you again.

Format: `topic -> where to look (and how)`

- Supplier contracts and amendments -> SharePoint "Procurement-Contracts" site, search supplier name + "agreement"
- PO / spend questions -> SAP Ariba spend cube; for one-off PO lookups ask the "PO-Bot" chat agent in Teams
- Org acronyms and shorthand -> global/acronyms.md first, then the intranet glossary
- Tool pricing baselines -> "CapEx cost model FY26.xlsx" on the Category-WetProcess Teams channel
- In-flight negotiation context -> recent mail threads with the supplier team (search sender domain, e.g. @tel.com)
- Service contract SLAs and uptime actuals -> maintenance dashboard, "Equipment Uptime" report, monthly export
- Supplier financials / risk -> annual reports + the quarterly risk memo from Corporate Risk (Teams: Risk-Watch channel)
- IT/AI platform questions -> #ai-enablement Teams channel
