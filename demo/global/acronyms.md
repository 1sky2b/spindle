# Acronyms and shorthand

One per line. The agent reads this instead of asking.

- CD-100 - TEL's coater/developer platform installed in Fab 1 (12 tools)
- CMP - Chemical Mechanical Planarization (polishing process step)
- RFQ - Request for Quotation
- LTA - Long-Term Agreement (multi-year pricing contract)
- TCO - Total Cost of Ownership
- SLA - Service Level Agreement (for tools: guaranteed uptime %)
- AM - Account Manager (supplier-side)
- MCP - Model Context Protocol; the standard connector between data sources and AI tools
- BKM - Best Known Method
- MTBF / MTTR - Mean Time Between Failures / Mean Time To Repair
