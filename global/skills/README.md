# Global skills

Skills that apply across threads live here; thread-specific skills live in each
thread's own skills/ folder. A skill is one markdown file:

1. **When to use** - the trigger condition, first line
2. **Steps** - the exact procedure that worked
3. **Pitfalls** - what went wrong before and how to avoid it

The Librarian (Reflect & learn) creates and improves these automatically.
Prune ruthlessly: merge near-duplicates, delete stale ones.
